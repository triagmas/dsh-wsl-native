# Инструкции для Pi и других AI-агентов

## Язык общения — русский (обязательно)

- **Всегда отвечай владельцу на русском языке.** Это касается промежуточных сообщений, итоговых отчётов, статусов, объяснений, вопросов, описаний результатов тестов и передачи задач.
- Если задание, шаблон или исходные данные написаны по-английски, **ответ всё равно должен быть на русском**, если только владелец явно не попросил другой язык.
- Для новых комментариев и описаний PR, предназначенных владельцу, по умолчанию используй русский. Сохраняй английские технические идентификаторы (имена файлов, API, команды, названия тестов, сообщения компилятора, GitHub labels), когда перевод ухудшает точность.
- Не переводи содержимое кода, программные идентификаторы, машинные форматы и дословные фрагменты логов. **Пояснения к ним давай по-русски.**
- Не переключайся самопроизвольно на английский или немецкий. Изменение языка допустимо только по явному запросу владельца.

## Правила работы в репозитории

- GitHub и действующий Draft PR — источник истины. Перед изменениями сверяй ветку, HEAD и рабочее дерево.
- Рабочий DeepSeek Harness Desktop, его профиль и реальные пользовательские проекты **не трогать** без отдельного разрешения владельца.
- Не устанавливать тестовые сборки, не выполнять merge и не удалять пользовательские данные без отдельного разрешения.
- Отчёт по каждому этапу: HEAD, изменённые файлы и строки (+/−), результаты тестов/CI, известные ограничения, точное состояние установки и merge — **на русском языке**.
